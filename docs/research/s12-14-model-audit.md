# S12-14: KNC tuning model and runtime defaults audit

2026-11-14. Read-only audit for the lead; every change below is a proposal.
No compiler, runtime, runner, ADR, test or milestone criterion is changed.

The highest-value M4 investigations are the scalar/bridge cost model, serial
scheduling and indexed-memory costs. Correctness gates precede any affected
optimization. The runtime and OS rows follow for PhiNix; they are not reasons
to change M4's fixed programs, flags or scoring denominator.

## Scope and evidence

The GCC source inspected is `.work/_shared/gcc`, branch `knc`, revision
`619e14b479a952edff32e94f22573710d0b8ac17`, also used by the
[digest](knc-digest-2026-11.md). Project source locations refer to this ticket's
base `43ce3e5b861a7be34b26500b32141e258d887519`. GCC paths below start with
`gcc/`, `libgcc/`, `libgomp/` or `libgfortran/`; other paths are project paths.
Line numbers count newline characters, including in GCC files containing form
feeds. These revisions identify source, not an installed compiler or DSO.

[R-numbers](knc-references.md) retain the index's editions and printed pages.
**V** means verified source evidence, including a publication's description of
its own experiment; it does not mean reproduced here. **R** means a reported
project measurement cited by the code/digest, whose original results were not
requalified in this audit. **E** means an estimate or inference. Hardware
timings from R06, R09, R14 and R20 retain their pre-production status. R02 is
descriptive, not a stepping-qualified timing experiment. R24 is upstream glibc,
not proof of the installed MPSS allocator or math implementation. Code values
and control flow in the tables were read directly.

The risk column records **C** (correctness), **A** (ABI/calling convention),
and **X** (x86 identity). `X=guard` means a future change must remain behind
KNC dispatch and receive the lead's ordinary ADR-0006 batch identity check if
shared code changes. `X=none` means a KNC-only file, project tool, or prose
change; it does not excuse expanding that change into shared behavior.

Ranks are qualitative, not speedup forecasts: **M4-1** before **M4-2**, then
**P1** before **P2** for PhiNix/later. A **gate** takes precedence when its
trigger applies. Rows in each section follow that ordering. Related rows share
experiments; their estimated times must not be added as independent campaigns.

## Coverage and disposition

The audit covers the KNC processor-cost initializer, its generic placeholders,
tune alias/overrides, scheduler reservations and cost hooks, prefetch pass
parameters/hints, vectorizer costs/tails/unrolling, driver defaults, libgomp
topology/waits/barriers/arena initialization, vector-library binding, fenv
helpers/startup and runner reservation/memory/profile defaults. Groups of
related estimates share rows rather than implying independent measured facts.

The source does not establish deployed kernel handling for CD3/CD9/CD13,
CD14/CD19/CD26/CD28, power errata or DMA/uncore errata. Their detailed OS triggers
remain in the digest's runtime table. They do not imply an additional compiler
constant to change; B17/B23/K09 identify the audited interfaces that could rely
on them. No matching MPSS kernel, ICC header, vendor math implementation,
Intrinsics Guide XML, ISPC source or held-out benchmark artifact was opened.

No GCC build, program test, native job or x86 identity check ran in S12-14.
Existing tests are cited as future proof, never reported as passing here.
The only deliverable is this audit; the lead turns accepted rows into tickets.
