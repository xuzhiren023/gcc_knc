From S12-15 (item 29, "what we overlooked" row 14): our vector math library was qualified function by function
(S10-02..S10-12) against ULP limits, but there is no written contract for what it promises beyond ULP: behaviour
under non-default rounding modes, special values and signed zeros, which FP exception flags may be raised, errno,
and when the vectorizer must fall back to scalar libm. Write `docs/research/s12-20-vmath-contract.md`: the contract
(per function family), how each clause is checked today (S10 screens, card_qualify, host MPFR recheck) and which
clauses nothing checks, and a validation design that covers the gaps with bounded host and card runs (time
estimates). Draft until S12-18 settles the double exp/log/pow path. Proposes ADR-0014 amendments; the lead writes them.
