Triage row C1 (docs/research/gpt-pro-2026-11-15-triage.md). Verified 2026-11-15: `gcc/modulo-sched.cc:347` gives up
when `targetm.code_for_doloop_end` is null, and no `doloop_end` pattern exists under `gcc/config/i386/`, so
`-fmodulo-sched` never transforms a loop for KNC. An in-order core that issues every other cycle per thread gains most
from overlapping iterations (II >= max(ResMII, RecMII)).

Phase 1 (probe; a no-change close is allowed): add a KNC-only counted-loop pattern behind a switch, show with
`-fdump-rtl-sms` which loops in three hand-picked kernels (a strict FP recurrence, an independent-iteration scalar
loop, a vector loop) SMS schedules, and compare final post-RA assembly and one-core card time against today. Report
spills and code size. Decide: adopt (phase 2 ticket) or close with the reason. x86 unchanged (ADR-0006).
