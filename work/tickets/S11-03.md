Found in the lead's card turn, 2026-11-12 14:14Z (boot da3144f1). The S11-01 native run stopped before any
transfer: the card helper printed `ERROR not a card_run directory (errno=0)` and exited 2, and the host runner
then timed out in `listener.accept()` (`.work/_shared/tmp/claude-next18/s1101-part1.out`,
`card-control-part1.log`). No SCIF or DMA operation ran.

Cause: the card links `/tmp` to `/var/volatile/tmp` (`docs/card-run.md`, the paragraph on `cd /tmp && pwd -P`).
`lease()` in `tools/transfer_bench.c` takes `getcwd()`, which returns the physical path, and requires the
literal prefix `/tmp/claude/claude-`. The host runner's lease check
(`re.fullmatch(r'/tmp/claude/claude-[a-f0-9]+', ...)` in `tools/host_card_transfer.py`) has the same
assumption.

Fix it the way card_run does: resolve `/tmp` physically once (`realpath("/tmp")` on the card) and require the
cwd to be exactly that prefix plus `/claude/claude-<32 lowercase hex>`; the host accepts the reported
directory if it is `/tmp/...` or `/var/volatile/tmp/...` with that same tail, and uses it as reported. Check the
rest of the tool for the same assumption (any path built from `/tmp/claude` on either side). Rebuild
`transfer-card.mic` with the GCC-KNC prefix, lint it, and restage `.work/_shared/S11-01/` (the staged
`host_card_transfer.py` too).
