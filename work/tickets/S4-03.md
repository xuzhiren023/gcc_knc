Backlog E4-01, part 2. Design: ADR-0007. S4-02 delivers compares, `vcond_mask` and blends, so
`c[i] = a[i] > b[i] ? x[i] : y[i]` and the `a < b ? a : b` idiom may already vectorize. Check them
in the red step, and keep a scan for each. Add the rest, for V16SF, V8DF and V16SI:
- `if (a[i] > 0) c[i] = x[i];` for a global or possibly-aliased `c`, through `maskstore` (and
  `maskload` for a conditional load). It is an aligned masked `vmov*{k}` only where ADR-0007
  point 7's line rule allows, which in S4-03 means a 64-byte aligned access with a non-empty mask
  (guard with `jkzd`). Otherwise do not provide it, and the loop stays scalar. The general
  misaligned split is S4-05;
- `fabs` (sign-bit `vpandd` with a broadcast constant), `fmin`/`fmax` (`vgminps`/`vgmaxps`,
  pp.333-348: check their NaN and signed-zero behaviour against C before using them, and if they
  differ, leave `fmin`/`fmax` to the scalar path), and integer `smin`/`smax`/`umin`/`umax` for
  V16SI, with `-O2 -ftree-vectorize` semantics (no `-ffast-math`): NaN and signed zero exactly as
  the scalar code gives them;
- KNC mask-logic insns in `imci.md` (`kand`, `kandn`, `kor`, `kxor`, `knot`, `kmov`), so
  `if (a[i] > 0 && b[i] < 0)` keeps its masks in `k` registers instead of going through GPRs (S4-02
  left mask logic in GPRs). The QI high-byte hazard applies (ADR-0007 point 1);
- conditional arithmetic (`if (m[i]) c[i] += x[i];`), if ADR-0007 maps `cond_<op>`.
