Backlog E4-01, part 1. Design: ADR-0007 (the lead writes it from S4-01; this ticket stays draft
until it is accepted). Rules: ADR-0006 forms for every shared change, and new patterns in
`imci.md`.

Deliver what ADR-0007 names for compares:
- `get_mask_mode` for V16SF, V8DF, V16SI and V8DI under KNC;
- compare expanders into `k` masks for every C comparison (`==`, `!=`, `<`, `<=`, `>`, `>=`, and
  the unordered forms GCC asks for), signed and unsigned for V16SI;
- mask logic, and moving masks between `k` registers, GPRs and memory, including spills and
  reloads under register pressure.

Blends and if-conversion are S4-03; this ticket only makes compare results exist and survive
register allocation.

Acceptance:

- [ ] Red first: T1 tests that a compare loop (`m[i] = a[i] < b[i]` stored as int) uses an IMCI
  compare into a `k` register, for each predicate and mode, and fail today
- [ ] Each predicate's NaN behaviour matches C (`tests/acceptance/s4_masks` has the exact cases)
- [ ] A function with more than 8 live masks spills and reloads them correctly (T1 scan plus the
  acceptance program)
- [ ] No other T0/T1/T2 outcome changes; KNC assembly over torture `-O0`/`-O2` changes only in
  functions that compare vectors (list them)
- [ ] Incremental build via `tools/gcc_build.py`; no x86, drill or trunk run (batch S4-06)
- [ ] After merge the lead runs `tests/acceptance/s4_masks` (compare part) on the card
