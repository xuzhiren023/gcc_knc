Found in the lead's card turn, 2026-11-12 17:05Z, after S11-04. The card helper announced
`{"ready":true,"port":47015,...}` and then printed `ERROR card TCP listener unreachable: no host connection
within 10 seconds`; the host's connect was refused (WinError 10061) because the listener had already closed
(`.work/_shared/tmp/claude-next20/card-control-part1.log`, `s1101-part1.out`). Cause: card_run relays program
output to the host only every 10 seconds (`tools/card_run`, the `next_output` poll), so the announcement can
reach the host 10+ seconds after it is printed, after the card's 10-second accept deadline.

Fix: the card's lease listener waits for the host at least as long as the host's announcement deadline plus the
relay interval (for example 90 s), and the per-method TCP endpoints likewise exceed their host-side deadlines;
keep the nonce check. State the deadline relation in a comment next to each constant. Check that the per-method
endpoints launched over SSH (not through card_run) are not affected the same way. Rebuild with the GCC-KNC
prefix, lint and restage `.work/_shared/S11-01/`.
