Owner 2026-11-15: the lead built `knc-twin/`, a standard-library Python twin of one KNC core (SKILL.md, scripts/knc_twin.py),
so candidates can be checked, timed and bounded off-card. Read `knc-twin/SKILL.md`, `knc-twin/references/architecture-model.md`
and `knc-twin/references/input-format.md` first. Its bundled tests pass (72) but nothing has been tried on real compiler output,
and no prediction has been compared with a native number. This ticket is that trial. No card run, no GCC build.

Deliver:
1. Run `python knc-twin/scripts/knc_twin.py selftest --out <dir>` and `python knc-twin/examples/run_examples.py --out <dir>` from
   the repo copy; record pass counts and any failure verbatim in the report.
2. Three real inner loops compiled by GCC-KNC at `-O2 -march=knc` with the frozen prefix `.work/_shared/gcc-knc-16.2.0`
   (saxpy over float, a sum reduction over float, and one stencil from `tests/t1/` or the corpus). For each: strip the inner
   loop to the GAS AT&T subset, write a kernel JSON (`asm_file`, init registers and memory, expected output computed by a host
   C reference or by hand with integer-valued data, `unit_of_work`, `loop`), then run `functional`, `simulate` at
   `--contexts 0`, `0,1` and `0,1,2,3` (replicate the stream per context with disjoint arrays), `bounds --loop`, and
   `compare` baseline vs one hand-modified order. Keep kernels under `knc-twin/fixtures/trial/`.
3. Check against measured rows (docs/research/knc-characterization.md): write the C9 register chains u1/u2/u4 (dependent
   `vaddps`, loop with pointer add and counter) and the C7 1- vs 2-accumulator reduction as kernels, simulate at 1 and 2
   contexts (C9) and 4 contexts (C7), and tabulate predicted cycles per update against the measured 4.02/3.02/2.52 (1 thread),
   4.02/3.01/2.51 (2 threads) and 4.13/4.13 (4 threads). Also `pair.vector_scalar`, `pair.vector_vector`, `agi.gap0/gap1`.
   Report the differences; do not tune the profile to fit.
4. Report: `docs/research/knc-twin-trial.md` (at most 120 lines): every mnemonic, operand form or directive the parser
   rejected in real `-O2` output (exact text), every parameter a run stopped on, the C9/C7 table, the three loops'
   predictions with result paths and exact commands, and a list of disagreements between `knc-twin/profiles/card-7120-measured.json`
   and `docs/research/knc-machine.yaml` (S13-05, if merged by then). Mark every number as predicted or measured.
5. One host test `tests/regress/test_knc_twin.py` that runs `knc_twin.py selftest` and the trial kernels' `functional` check
   through `tools/run.py`; no other tests (over-testing is a finding).
