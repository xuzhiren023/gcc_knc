snapshot's `awk` program in `tools/card_run_remote.sh` is
`name = name (lines++ ? "?" : "") part`: BusyBox v1.19.4's `awk` reads `name (` as a call to a
function `name`, where GNU `awk` (which the Cygwin fake runs) reads concatenation. No BusyBox is
available on this host, so T0 cannot run the card's `awk`.
