Follow ADR-0001. The owner created the private repository
`https://github.com/xuzhiren023/gcc_16_knc.git`, which is empty. Clone GCC from upstream into
the shared build area, keep upstream as remote `upstream`, and add the private repository as
`origin`. Create local branch `knc` at the tag. **Do not push:** the owner does that.

Acceptance:

- [ ] Tag `releases/gcc-16.2.0` checked out in the shared build area (`.work/_shared`, one copy only) with `core.autocrlf=false` and `core.fileMode=false`, and a clean `git status`; case-collision check done
- [ ] Stock `x86_64` target `all-gcc` built in the shared build area, C and Fortran front ends, with GCC 14.4 on Cygwin
- [ ] **Measured and recorded:** disk used by the checkout and the build tree, configure time, full `all-gcc` time, incremental rebuild after touching `i386.cc`, and a one-file `.md` change. Peak memory if practical
- [ ] Recommendation: does the T1 budget (≤ 5 min) look reachable on Cygwin? This feeds Milestone M0
- [ ] Does `config.sub` in GCC 16.2 still accept `k1om-mpss-linux`? Note the result without patching
