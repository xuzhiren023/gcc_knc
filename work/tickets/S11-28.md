Found by the M4 pilot (lead, 2026-11-13; `CURRENT_STATE.md` 14:30 EST; `.work/_shared/S11-18/`). Owner 2026-11-13:
the HPCG case must not ask the 3100- and 5100-series cards for what their hardware cannot do. Design one that
fits them, and run it again.

Two problems:
1. **The work is not fixed.** `hpcg.dat` asks for 60 s, and HPCG 3.1 `main.cpp:316-317` runs
   `numberOfCgSets = int(total_runtime / opt_worst_time) + 1`. A faster build therefore does more sets in about the
   same time. Wall time cannot measure speed (pilot serial: GCC-KNC 0.0850 vs GCC 5.1.1 0.0864 GFLOP/s rating, time
   equal), and ADR-0015 (Timed boundaries, HPCG row and the paragraph after the table) requires equal work. HPCG's
   rating is diagnostic only, never the score.
2. **OpenMP HPCG aborts under the smaller profiles.** At 2 and 4 threads per core under `--profile 3100`
   (5632 MiB) and `--profile 5100` (7680 MiB) it fails in about 2.3 s with `std::bad_alloc`, exit 134
   (`capture/340.stdout`, 341, 358, 359, 394, 395, 412, 413). The same build passes at 1 thread per core and on the
   full card. card_run applies the profile as `RLIMIT_AS`, which counts reserved address space (thread stacks, glibc's
   per-thread malloc arenas of up to 64 MiB each), not memory in use. A real 3120 has 6 GB of RAM and does not limit
   address space. The failure may therefore be our simulation, not the hardware. Measure before choosing.

  - Sample the process's `VmPeak`, `VmHWM` and `VmSize` from `/proc/<pid>/status` about every 0.5 s.
  - Rerun one failing case with `MALLOC_ARENA_MAX=2` to test the arena explanation. This is diagnostic only and
    never part of the primary environment.
  - Add candidate smaller grids (for example 96³, 88³, 80³) at 224 threads under 3100.
  - One `card_run` per profile case; the cases cannot share a job.
- **Grid choice from the results:** the largest grid whose peak *resident* memory (`VmHWM`) fits the 3100 profile
  at 4 threads per core with at least 20% headroom, used identically on all models (ADR-0015: "identical primary work
  across models, sized to the smallest profile").
  - If `VmHWM` fits at 104³ but the run still fails on `RLIMIT_AS`, say so plainly: then the profile, not the
    hardware, is the limit. Recommend the card_run profile change in the report, but do not change card_run here.
  - Update the harness's frozen HPCG configuration to the chosen grid and fixed work.
- **An HPCG-only pilot script for the lead** (timed, exclusive, as the S11-18 pilot): serial for both compilers and
