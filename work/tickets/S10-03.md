ADR-0014 points 2-3. Add an i386-style vector library hook `-mveclibabi=knc` (on by default under
`-march=knc`): the vectorizer replaces vectorizable `expf`/`logf`/`powf`/`exp`/`log`/`pow` calls by
`__knc_vmath_<name>_<lanes>` (16 lanes float, 8 double). Add the by-value entry points to
`libknc_vmath` using S10-01's convention; install it in the prefix and name the static archive in the
KNC link spec after `-lm`. `-mphinix` adds `-fno-math-errno`; update the flags page.

Acceptance:

- [ ] Red first: T1 scans that a loop of `expf` at `-O2 -march=knc -fno-math-errno` calls
  `__knc_vmath_expf_16`, and with `-fmath-errno` stays scalar
- [ ] A program that links with no extra flags and gives the same results as the scalar loop within
  the S10-02 limits, staged for the lead's card run
- [ ] x86 unaffected (the lead runs the x86 check)
