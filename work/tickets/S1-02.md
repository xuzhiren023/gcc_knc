but `gcc/config.gcc` has no `k1om` case, so configure stops. Add the smallest routing that
builds: a `k1om-*-linux*` case using the x86-64 GNU/Linux headers plus a new
`gcc/config/i386/linux-k1om.h`. Defaults such as `-march=knc` and the link specs come in
S1-04 and S1-06, so the first output may still contain SSE; that is expected here.

The donor's equivalent is `gcc/config/i386/linuxk1om.h` and its `config.gcc` case, in
`.work/_shared/gcc-donor` (read-only). The S0-05 inventory marks them port and rewrite.

from S0-06, whose numbers are already recorded. Configure with `--target=k1om-mpss-linux`,
`--with-as`, `--with-ld` and `--with-sysroot` pointing at `.work/_shared/toolchain`,
`--enable-languages=c`, `--disable-bootstrap`, `--disable-multilib`, `--disable-nls`,
`--without-isl`, and the donor's `--disable-lib*` set. Add this as a `gcc16` step in
`tools/toolchain.py`, logged, using the host workarounds S0-08 found where needed.
