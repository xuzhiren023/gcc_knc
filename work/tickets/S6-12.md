Found 2026-11-06 14:49-14:55 UTC. The PhiWeather controller wrote a finish row for its physics run
(`claude-mentor-…bbf08b22`, outcome program-failure) while its 8 `wrf.mic` processes kept running
all cores. Our `--benchmark` jobs `claude-…4024e5e3` and `claude-…03cf17f5` were admitted, because
admission reads only the ledger, and their timings are invalid. card_run already lists card-side
foreign processes in every result (`foreign_processes`), so it can see this.

Deliver:
- Before a `--benchmark` job is admitted (and again just before the timed program starts), card_run
  takes the card process snapshot it already takes and refuses, with "foreign workload running"
  and the process names, when any process outside the configured baseline set (`baselineNames`,
  the OS daemons) is using CPU. Waiting within the admission timeout first, as for cores, is fine.
- Non-benchmark jobs keep today's behavior (they share cores by the ledger rules).
- One line in `docs/card-run.md`.
