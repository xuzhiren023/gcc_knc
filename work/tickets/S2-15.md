`gcc/config/i386/linux-k1om.h:50` (ported from the donor in S1-06) still adds `crtfastmath.o` for
`-mdaz-ftz`, `-Ofast`, `-ffast-math` and `-funsafe-math-optimizations`. S2-07's `libgcc` rightly
builds no fast-math startup file (`libgcc/config.host:807-810`), so those links should now fail to
find it. If an old copy were found, it would write MXCSR with SSE's FTZ/DAZ bits. KNC's MXCSR is
not SSE's (`docs/research/phiweather-scan.md`, from Intel 327364-001 Table 2.15): the SSE default
`ldmxcsr 0x1f80` faults on the card, and FTZ and DAZ are not known to be settable.

Remove `crtfastmath.o` from the KNC end-file spec. Do not provide a KNC replacement in this
ticket: setting FTZ/DAZ on KNC is unproven.
