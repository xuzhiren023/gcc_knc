Backlog E5-17 (Fable gap review, `docs/research/knc-optimization-gaps.md`). A folded load costs no
extra U-pipe slot on KNC, and hand IMCI folds most loads; GCC-KNC emits separate `vmovaps` loads.
First count separate loads in the M2 kernels (T1 scan, in the ticket). Then add memory-operand
alternatives (aligned full-line memory, and `{1to16}`/`{4to16}` broadcasts where ISA Table 4.2
allows) to every V16SF/V8DF add, sub, mul and FMA pattern in `imci.md`, with the cost entries.
Up-converting memory operands are E4-07, not here.
