The card is shared with another project's agent, which runs jobs on it at the same time. The
owner set these rules for both sides on 2026-11-03, and `tools/card_run` must enforce them, not
rely on whoever calls it:

- Ledger: before each job, read the shared ledger (path in `config/card.local.json` as `ledger`).
  Append one JSON line when the job starts (`agent: "claude"`, job ID, cores, memory, start,
  expected end) and one when it ends, including after failures.
- Cores: only physical cores 30-59; never core 60 (the OS core). Map cores to logical CPUs from
  the card's `/proc/cpuinfo` (`core id`), not by assuming a numbering, and pin every job to those
  CPUs. If the card has no way to pin, refuse rather than run unpinned.
- Memory: at most 7 GB resident for all our jobs together, and each job declares its limit
  (default small) and is held to it. Read `/proc/meminfo` first: if free memory would drop below
  about 1.5 GB, the job waits and is not started. The card's filesystem is RAM: stage under
  `/tmp/claude/<job-id>/`, copy results back, and delete our files when the job ends.
- Names: job IDs, directories, process names and any ports start with `claude-`. Never signal,
  kill or remove anything that is not ours. Other users' processes are listed in the result, not
  refused.
- No card-global change of any kind (reboot, MPSS, modules, sysctl, huge pages, `/etc`).
- Card fault (boot ID changed, card unreachable mid-run): append a `card-fault` line to the
  ledger, exit as an infrastructure failure, and ask on the ticket; the lead escalates.
- No timing figures: the result records which ledger jobs overlapped ours, so later timing work
  can tell whether the card was exclusive.

This replaces the S0-04 policy of refusing on foreign processes, and the `/tmp/knc-phase3-
workload.lock` check from the earlier notes below; drop both. Also fix two gaps found on
2026-11-03: the runner stopped with remote status 94 (`tools/card_run:176-177`) because a
required tool is missing on the card's BusyBox, without naming it; and `--config` defaults to the
worktree, which has no copy of the git-ignored file (resolve it to the main checkout's, as
`default_lock` does at `tools/card_run:36-41`; never copy it). Use the card only through
`tools/card_run`. Build `hello` with the donor as `tools/check.py` does.
