ADR-0014 point 1. Today a 64-byte vector argument or result is an error under `-march=knc` (ADR-0005
point 6). Make `__m512`/`__m512d`/`__m512i` and `vector_size (64)` types pass in `zmm0`-`zmm7` (shared
with the scalar float/double sequence of S2-02), further ones on the stack 64-byte aligned, and return
in `zmm0`; vector arguments to variadic functions stay an error. Check against Intel's K1OM psABI
supplement if obtainable (facts only, ADR-0013) and record the result.

Acceptance:

- [ ] Red first: T1 scans that a function taking and returning `vector_size (64)` float compiles under
  `-march=knc` with arguments in `zmm0`/`zmm1` and the result in `zmm0`; mixed scalar and vector
  arguments take the expected registers; a ninth vector argument goes on the stack at a 64-byte aligned slot
- [ ] A cross-translation-unit card test (caller and callee in separate objects, including `-O0`),
  staged for the lead
- [ ] Shared i386 lines reported (ADR-0006 forms); x86 unaffected (the lead runs the x86 check)
