Lead 2026-11-16 (Codex, never Fable; needed before the 06:30Z calibration window). Defect from PhiWeather's
sixth_order_diffusion native request: `knc_twin.py prepare-native` writes a memory operand that has no base,
index or symbol (an absolute address, parsed by `scripts/knc_model/asm.py` as `{"disp": N, "abs": true}` and
produced by `scripts/from_binary.py` for linked executables) as `N()` in `kernel.S`, which the K1OM assembler
rejects. The staging copies were hand-relocated (`.work/_shared/calib-w10/phiweather/`, originals `kernel.S.orig`).

Fix, in `knc-twin/scripts/knc_model/asm.py` `emit_gas` and `scripts/knc_model/native.py` `gen_kernel_asm`
(branch twin/0.3 is merged to main; work on main's knc-twin/):
- `emit_gas` takes an optional relocation callback (or `mem_base`/`mem_span`) from `gen_kernel_asm`. An absolute
  operand whose address lies in the memory image is emitted as `knc_twin_mem+<addr - mem_base>(%rip)` (the same
  relocation `gen_kernel_asm` applies to register initial values at lines 100-101); one outside the image is an
  `InvalidInput` naming the instruction and address (never `N()`); without a callback (other callers) an absolute
  operand is emitted as a plain decimal displacement `N` (valid GAS for `N(,1)` is `N`), not `N()`.
- `%rip`-relative symbol operands already resolved to absolute displacements by `kernel.Stream` are the same case:
  check that `symbol(%rip)` operands relocate too.
- Red first: one new test file (`tests/test_native_emit.py`) that builds a kernel with an absolute operand inside the
  image and one outside, runs `prepare_native` into a temp dir, asserts the `knc_twin_mem+off(%rip)` text, the
  `InvalidInput` for the outside address, and that no `()` with an empty inner appears anywhere in `kernel.S`;
  plus the PhiWeather kernel if its path is readable (`...twin-study-20261116/sixth/held-out/...`), skipped otherwise.
- Then `knc_twin.py selftest` and `tests/regress/test_knc_twin.py` (single-threaded). Nothing else changes.
Submit with the one-sentence note the owner reads. Host: no builds, no card.
