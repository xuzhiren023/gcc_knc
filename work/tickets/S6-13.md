per element per build, measured during each build's timed groups.

samples, `docs/research/card-runs-s6.md`).

Deliver, in `tests/acceptance/m2_kernels/` (this ticket may change it):
- Find the card-side power source and cite it: MPSS's `micras` sysfs power file (likely
  `/sys/class/micras/power`; Intel 330991 and MPSS documentation for its fields and units). If the
  path or units are uncertain, print the raw file once per launch and say so in the README.
- A sampler thread on the OS core's side of the card (not on a worker CPU) that reads total card
  power about every 50 ms during each build's timed groups, and prints per build: samples, mean,
  min, max watts, and joules per element (mean watts x median ns per element).
- If the power file is missing or unreadable, timings still run and the power lines say
  `power=unavailable` with the errno; never fail a timing run for lack of power data.
- README: the power lines' format and what they mean (whole-card power, including idle and memory).
