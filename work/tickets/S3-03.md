Backlog E3-01, before any unaligned or masked design. KNC has no `vmovups`: an unaligned access is
a `vloadunpackl*`/`vloadunpackh*` or `vpackstorel*`/`vpackstoreh*` pair, `l` at the address and
`h` at the address plus 64. `m1_affine` puts arrays flush against a `PROT_NONE` page, and
ADR-0005 point 4 allows `movmisalign` only if a pair wholly inside mapped memory never faults.
Masked tails (E4-04) also need to know whether masked-off lanes on an unmapped page fault.

Engineer sessions have no card access. Write the probe, build it, and prepare a batch; the lead
runs it through `tools/card_run` and fills in the observed results. Intel 327364 must be under
`.work/_shared/`; if it is missing, ask.

Deliverables:

- A self-checking C probe in `tests/regress/` (inline assembly, built with GCC 16 or the donor,
  assembled with `--march=k1om`, lint clean). It maps a region with a `PROT_NONE` page after it and
  one before it, recovers from `SIGSEGV` with `sigsetjmp`, and prints one line per case: form,
  offset, fault or not, lanes or bytes transferred, and whether sentinel bytes changed
- `docs/research/knc-unaligned-probe.md`: for each form, what 327364 says about faults (section
  cited) and the expected result, with an empty observed column for the lead
- `.work/_shared/tmp/S3-03/`: the program and a `batch.txt` (program, arguments, memory limit)

Cases, each for `ps`, `pd`, `d` and `q`:

- [ ] Load pair and store pair at every element offset 0-63 from the end of a mapped region (data
  ends at the guard page) and from the start of one (data begins right after a guard page)
- [ ] The aligned case on its own: the address is 64-byte aligned and address plus 64 is the first
  byte of the guard page, for the `h` load and the `h` store
- [ ] Masked aligned `vmovaps`/`vmovapd` load and store with `{%k}` where every masked-off lane is
  on the guard page, and where the mask is empty
- [ ] Stores change no byte outside the intended range
- [ ] The probe's host-side logic (case table, sentinel checks) has a T0 test; the instructions run
  only on the card
