Backlog E5-01; ADR-0009 points 1-5. Method: S6-01's protocol. These tables feed S6-05 (costs) and
S6-06 (scheduler), so measure what those tickets need.

Deliver `tests/bench/knc-char/` with small programs, written in assembly where the compiler would
blur the measurement, that measure on the card:
- latency and reciprocal throughput of: vector FP add/mul/FMA, integer add/logic, `vpermd`,
  `vpermf32x4`, swizzles, `vgatherdps` (all lanes, scattered lanes), masked aligned loads and
  stores, `vloadunpack`/`vpackstore` pairs, up/down-converting moves, `vrcp23ps`, `vcvtfxpnt*`,
  x87 add/mul/div, scalar integer ALU, `kmov`/mask ops, and a `zmm` spill and reload through the
  stack;
- each at 1, 2, 3 and 4 threads per core;
- U/V pairing: a vector instruction followed by a scalar one, and by another vector one;
- the address-generation interlock: pointer update to use at 0-4 cycles apart;
- load latency and bandwidth for L1, L2 and memory working sets; streaming stores versus normal
  stores.

Each program prints one line per measurement (name, threads per core, cycles). The lead runs them
as `--benchmark` jobs and records the tables in `docs/research/knc-characterization.md`.
