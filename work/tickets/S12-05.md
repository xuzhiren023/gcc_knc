S11-02 card validation, 2026-11-14: link 1.41 GB/s up and 1.67 GB/s down, but a 1 GiB file takes 6.1 s up and 4.6-5.3 s down because the phases run in series. Up is host read 0.3-0.8 s, then DMA 0.76 s, then a card tmpfs write of 2.9 s on a single thread, plus about 1.5 s of SSH and helper startup.

Deliver: chunked pipelining (read, DMA and write overlap in a ring of registered buffers) and a multithreaded card-side copy. Target 1 GiB end to end at 2.5 s or less each way, measured 3 times on the idle card. Keep exact length and publish-after-complete, with no digests (owner 2026-11-13).

Also batch helper-free SSH finish_ssh's per-file wc -c round trips (303 for 300 files) into one call.
