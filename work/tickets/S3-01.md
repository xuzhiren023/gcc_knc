- [ ] For each of the four modes, every standard name that vectorizing the `m1_affine` loops and
  V16SI add, sub, mul, and, or, xor needs, including `mov`, `movmisalign`, `vec_duplicate` and
  `vec_init`: where it is instantiated (`sse.md`, `mmx.md`, `i386.md`, or nowhere), its condition,
  its iterator entry, and what its body calls
- [ ] For each iterator ADR-0005 point 2 would widen: every pattern using it, and whether its whole
  condition becomes true under KNC with only that entry widened. Name each one that would
- [ ] Whether a second definition of an existing standard name in `imci.md` fails to build, shown
  from the generator source (`gencodes.cc`, `genemit.cc`, `genopinit.cc`), not by building
- [ ] Every hook the vectorizer, expansion or register allocation reaches for these modes that
  tests SSE or AVX-512, at least: `preferred_simd_mode`, `vector_mode_supported_p`,

  327364 (swizzle groups for 64-bit elements), or a statement that there is none
- [ ] Which cost model applies at `-O2`, `-O2 -ftree-vectorize` and `-O3`, and whether the
  `m1_affine` loops need peeling, versioning or `movmisalign` under each, given the driver's arrays
