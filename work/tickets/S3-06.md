(ADR-0005 point 2), and `vec_duplicate` for both, which goes only in `imci.md`. FMA comes only from
contraction. Division and square root stay scalar (ADR-0003). Tests use GCC vector types under
`--vector`.

- [ ] Red first: T1 tests for each operation and mode fail before the change
- [ ] `a + b`, `a - b` and `a * b` are each one IMCI instruction; a memory operand appears only
  where it is known to be aligned
- [ ] With `-ffp-contract=off` there is no `vfmadd*`; with `-ffp-contract=fast`, `a * b + c` is one
  `vfmadd*ps` or `vfmadd*pd`
- [ ] A broadcast of a scalar from memory is `vbroadcastss` or `vbroadcastsd`. From a register it
  goes through S2's lane store, or S3-01's register sequence if ADR-0005 adopted it
- [ ] `a / b` and square root on these types produce no vector instruction
- [ ] No regression, as in S3-04
- [ ] Native, in S3-10: each operation on inputs with exactly representable results matches its
  exact value, and signed zero, infinity and NaN pass through add and mul as IEEE requires
