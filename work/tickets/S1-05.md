Backlog E1-03 and E1-04. GCC 16 emits syntax newer than binutils 2.22 accepts in places; for
example it defaults to DWARF 5, whose `.file 0` form old assemblers reject. Configure already
probes the assembler for many features, so find what still breaks by measurement, not guesswork.

Corpus: every file in `gcc/testsuite/gcc.c-torture/compile/` of the fork, compiled with
`-march=knc` at `-O0`, `-O2` and `-O2 -g`, then assembled with `as --march=k1om` and linted.
Script it so it reruns in one command, with results outside git and a summary in git.

Classify each failure: ICE, compiler error, assembler rejection, or lint failure. Errors that
come only from float or double arguments and returns are their own class, expected until E2-01.

Acceptance:

- [ ] Summary committed as `tests/baseline/gcc16-torture-compile.txt`: counts per class and level,
  and the file list for every class except passes
- [ ] Zero assembler rejections and zero lint failures. Fix them in the fork, red first with a
  reduced `tests/t1/` case for each distinct cause
- [ ] `-g` output assembles: choose the default DWARF version for `k1om`, with the reason in the
  commit message (the card's debugger version decides it; ask if unknown)
- [ ] Every ICE class has a reduced `tests/t1/` reproducer and is fixed, or is recorded on the
  backlog with its reproducer if it needs SSE-free FP (E2) or vector work (E3)
- [ ] The whole run's time recorded, for S1-07
