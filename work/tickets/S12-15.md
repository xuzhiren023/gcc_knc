Owner, 2026-11-14: search the published record for Xeon Phi work that matches our goals, to find historical research
we may have overlooked on this platform. Our goals: a modern general-purpose compiler for KNC (GCC-KNC: code
generation, vectorization with masks/gathers, scalar code, cost models, PGO), its runtimes (libgomp, libm/vector math,
malloc), memory bandwidth and host-card transfer, a modern Linux on the card (PhiNix: kernel, scheduling, memory
management, multikernel/lightweight-kernel designs), LLM inference (GEMV/weight streaming, quantization), and
scientific codes (WRF, HPCG, sparse and dense linear algebra, stencils, MPI symmetric mode).

Start from `docs/research/knc-references.md` if S12-13 has merged it, else `docs/research/knc-reference-gaps.md`
part 2, so you do not repeat known sources. Search broadly and deeply: ACM DL, IEEE Xplore, arXiv, Springer, SC/ISC/
IPDPS/ICS/PACT/CGO/CC/LCTES/ROSS/HPDC workshop proceedings, Intel/IXPUG material, theses (any country, any
language), national-lab and supercomputing-centre reports (TACC, NERSC, ORNL, LRZ, Jülich, CSCS, NSCC Guangzhou /
Tianhe-2, CINECA, PRACE), and code repositories (compiler backends or forks for k1om, LLVM/ISPC KNC targets, KNC
ports of BLAS/FFT/ML frameworks, Linux on MIC such as IHK/McKernel, mOS, Popcorn, MPSS forks). Include KNL work only
where it transfers to KNC, and say why. Note anything from 2018 to today (revivals, hobbyist work).

Download open-access papers into `.work/_shared/phi-literature/` (never git, under 2 GB). Write
`docs/research/phi-literature-survey.md`: a ranked list (most useful first) with citation, URL, local file, which of
our goals it serves, the 2-4 facts or methods we could use (page numbers), hardware/edition caveats, and whether it
contradicts anything in our notes. Then a short section "what we overlooked": ideas, tools or results we have not
used and the ticket each suggests. ADR-0013 holds; no copied text.
