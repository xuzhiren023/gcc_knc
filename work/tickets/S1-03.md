DejaGnu is not installed (`tools/doctor` reports it absent), so Sprint 1 needs a small
scan-test format of its own until T4. Later tickets only add test files.

`tools/check` gains `--compiler gcc16`, which uses the build tree's driver,
`.work/_shared/gcc-build/gcc/xgcc -B.work/_shared/gcc-build/gcc/`. The donor stays the default.
With `gcc16`, `t1` also compiles every `tests/t1/*.c` with the flags in its header and checks
these directives, one per comment line:

- `// options: <flags>`, default `-O2`
- `// scan-asm: <regex>` and `// scan-asm-not: <regex>`, against the `.s` of the whole file
- `// scan-asm-func <function>: <regex>`, limited to that function's body
- `// error: <regex>`, which expects the compile to fail with a matching diagnostic

Each compiled test is also assembled with `as --march=k1om` and linted with `tools/knc_lint`,
unless it expects an error. A test counts once: pass, fail with the first unmet directive, or
error. Results print in the same style as today's T1 lines.
