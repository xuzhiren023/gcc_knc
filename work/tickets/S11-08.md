Found by the lead, 2026-11-12, installing libknc_vmath after S10-13. `#pragma GCC diagnostic ignored
"-Wknc-unsafe-cbrtl"` in a C file under `-march=knc` gives `error: option '-Wknc-unsafe-cbrtl' is valid for  but not
for C [-Werror=pragmas]`, and the warning is not silenced. The command-line `-Wno-knc-unsafe-cbrtl` works (S10-13's
T1). Cause: the option is declared in `gcc/config/i386/i386.opt` as `Target Var(warn_knc_unsafe_cbrtl) Init(1)
Warning` with no language flags, so the pragma's language check rejects it. Users need the pragma to silence one
deliberate call (the lead's workaround in `tools/knc_vmath.py` passes the command-line flag to qualify_v1).

Fix: declare the option so that `#pragma GCC diagnostic` accepts it in C, C++ and Fortran (see how other target
or c-family warnings that pragmas accept are declared; keep the KNC-only behaviour and the default on). ADR-0006:
smallest shared footprint. Do not build GCC: commit and `pm.py ask` "GCC build needed at <commit>" (owner
2026-11-12, AGENTS.md); the lead builds.
