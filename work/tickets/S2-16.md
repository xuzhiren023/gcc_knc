The lead cannot run S2-08's torture job: `tools/card_run` gets `[Errno 13] Permission denied` on
`.work/_shared/tmp/S2-08/claude-t-*.mic`, and Cygwin `cp` is refused too. `icacls` shows an
explicit `Y9000X\xuzhi:(DENY)(W,RD,REA,X,DC)` on those files and none on `hello.mic`. The cause
is `tools/prepare_s2_08.py:186`, `binary.chmod(0o700)`: under Cygwin, mode 700 becomes deny
entries for every other user, and the lead's Windows user is another user. Only the engineer
sandbox, which owns the files, can change them.
