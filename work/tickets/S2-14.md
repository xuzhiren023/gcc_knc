`tools/card_run` stages one program per job, and each job costs about 15 to 20 s of SSH setup,
admission and cleanup. S2-08 needs a first `gcc.c-torture/execute` baseline on the card, hundreds
of small programs. Let a job carry extra files next to the program, so a small driver can run
them all in one job.

- `--file PATH` (repeatable) stages each file into the job's run dir under its base name, by the
  same raw SSH stream as the program, with mode 700 for files that are executable on the host.
  Names must start `claude-` or be plain names without `/`; refuse duplicates and anything that
  would leave the run dir.
- The job's memory limit and core pinning apply to everything the program starts (they already do
  through `claude-pin`; state it in `docs/card-run.md`).
- Total staged size is capped (for example 64 MiB, in the config as `maxStageMiB`), because the
  card's filesystem is RAM.
