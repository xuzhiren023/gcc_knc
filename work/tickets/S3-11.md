Backlog E3-06. Milestone M1 asks whether the i386 subtarget is still cheaper than a separate
backend. Go if `m1_affine` is fully green, ABI cross-check included; shared i386 files carry at
most 300 changed lines outside the KNC files; and no SSE-assumption ICE class is open
(`docs/PROJECT_PLAN.md`, section 6). Measure and compare; the owner decides on the lead's
recommendation.

Deliverable: `docs/research/m1-result.md`, short. Separate measured from estimated.

Acceptance:

- [ ] Fixture: each README row with GCC 16, its result, and where it ran (host log, or the card job
  ID from `docs/research/card-runs-s3.md`)
- [ ] Lines at the final `knc` head, in the sprint's measure, per file and per sprint, with the
  KNC-only files (`imci.md`, `i386-knc.*`, `linux-k1om.h`) beside them
- [ ] ICE classes: the torture compile sweep at `-O2 -ftree-vectorize` and `-O3` at the final head,
  every ICE grouped by class with one reduced reproducer, and which classes come from SSE or AVX
  assumptions in shared i386 code, open or fixed
- [ ] Cost comparison. The subtarget's cost so far: shared and KNC-only lines, tickets, engineer
  sessions and input tokens from `STATUS.md`, rebuild times. A separate backend's estimated cost:
  what it would duplicate from i386 (x87, integer, ABI and varargs, prologue, atomics, scalar
  transfers), sized from GCC 16 and `docs/research/donor-inventory.md`, and the rebase cost each
  path implies. Every estimate says how it was made
- [ ] A recommendation, go, adjust or stop, with its reason
