Backlog E4-04. Design: ADR-0007 point 7 (`docs/research/knc-masks.md` section 5). Pieces:
`maskload`/`maskstore` expanders that enforce the line rule, `while_ult` in `imci.md`, `cond_<op>`
for FP, and the KNC term in `finish_cost` (masked epilogue only when every data reference is
known 64-byte aligned); `param_vect_partial_vector_usage` stays 0. S3-03 proved that masks
never suppress a fault and that an unaligned half touches its whole 64-byte line. So a masked
remainder is allowed only when every 64-byte line it addresses holds at least one element of the
array being accessed. Example: an aligned access after the vectorizer's alignment peel, whose
line starts inside the array. In every other case the x87 remainder stays (S3-07). Never read or
write a line the scalar loop would not touch.
