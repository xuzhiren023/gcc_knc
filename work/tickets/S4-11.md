S3-09 found the shared build's `.work/_shared/gcc-build/gcc/mddeps.mk` empty since 12:36 on
2026-11-04. A `make ... i386-knc.o` run inside `gcc-build/gcc`, without the top-level variables,
rewrote it. With `MD_INCLUDES` empty (`gcc/Makefile` around line 2805), edits to `imci.md` and
`sse.md` no longer regenerate `insn-*`. A build then "passes" with a stale `cc1`, and
`tools/gcc_build.py --if-stale` stamps it. `AGENTS.md` no longer recommends that command, but
nothing stops it.

Fix in `tools/gcc_build.py`, before deciding to skip and again after a build: read
`<build>/gcc/mddeps.mk`. If it is missing, empty, or does not list `config/i386/imci.md` and
`config/i386/sse.md` under `MD_INCLUDES`, do not skip. Delete `<build>/gcc/s-mddeps` so `make`
regenerates the file, run the build, and check again. If it is still wrong after the build, exit
non-zero and remove the stamp, so a build like that is never certified.
