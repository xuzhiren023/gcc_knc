Backlog E4-04; ADR-0009 amendment 1 order item 1. Today odd short lengths fall back to x87 scalar
tails, because a masked unaligned access can cross into the next page (S4-14 guarded split; S3-03
probe). Inputs: `docs/research/knc-characterization.md` section "Sprint 8 tuning checks" (S8-01), check C6 (tails at lengths 1-33: x87 scalar, aligned masked, peel plus
masked, gather tail), and `docs/research/card-runs-s6.md` for the M2 short-length losses.

Deliver, in the order C6 ranks them:
- an aligned masked epilogue for loops whose base is known 64-byte aligned (no page crossing is
  possible inside an aligned 64-byte line);
- a masked vector peel to alignment, then the aligned body and an aligned masked tail, for unknown
  alignment, chosen by the cost model at the C6 crossover lengths;
- whole-loop masking for constant or small trip counts below the vector length.
The x87 scalar tail stays only where C6 shows it wins. A masked access must never touch a line
outside the object: keep S4-14's guard-page tests and extend them to the new forms.
