Owner's user story (2026-11-10): "gcc can auto detect knc hardware model and adjust optimization
setting, user can also use cmd arg to turn the compiler work for specific knc hardware model."

All KNC cards share one core (same ISA, L1, L2, TLB), so the model changes tuning, never the
instruction set. What differs: core count (3100: 57, 5100: 60, 7100: 61), clock (1.1, 1.053,
1.238 GHz), memory bandwidth per core (about 4.2, 5.3, 5.8 GB/s) and memory size (6-8, 8, 16 GB).
The Sprint 8 defaults were measured on a 7120P only.

**1. The option: `-mknc-card=MODEL`**, declared in `i386.opt` in ADR-0006 form, expanded in KNC files.
- Values: `generic` (the default), `3100`, `5100`, `7100`, `native`. Card names map to their family:
  3110P/3115A/3120A/3120P to `3100`; 5110P/5120D to `5100`; 7110P/7110X/7120P/7120X/7120A/7120D to
  `7100`. Accept those names as aliases (`-mknc-card=7120` is `7100`).
- It sets the model's values for the card-dependent parameters only: today `knc-prefetch-l2-distance`
  and `knc-prefetch-l1-distance` (S8-03), and any other Sprint 8 default whose best value follows
  memory latency or bandwidth (list them; S8-13's streaming-store threshold follows cache size, so it
  does not change). An explicit `--param` still wins.
- Expand it as a driver self-spec in `linux-k1om.h`, so `-###` shows the resulting `--param`s.
- On x86 it is an error, and x86 code stays identical.

**2. Detection: `-mknc-card=native`**, a driver spec function (like `-march=native`'s
`host_detect_local_cpu`), resolved to a model before cc1 runs:
- Compiler running on a card (native GCC, the PhiNix case): count the cores in `/proc/cpuinfo` (`core
  id` values without the OS core) and read `MemTotal`.
- Cross compiler on a Linux host with MPSS: the cards under `/sys/class/mic/` (verify the file names
  against the MPSS 3.x documentation before using them). One model present: use it. Several
  different models: error that names them and asks for `-mknc-card=MODEL`.
- Nothing found (for example a Windows host): `generic`, with a one-line note on stderr.

**3. Defaults stay reproducible.** Plain `-march=knc` means `-mknc-card=generic`, so the same command
gives the same code on every machine. `-mphinix` (S8-16), the "do everything" flag, adds
`-mknc-card=native`.

**4. The values.** `7100` takes the Sprint 8 measured values. `3100` and `5100` start from a stated
model (prefetch distance in lines scales with memory latency x bandwidth per core at that clock), and
`docs/gcc-knc-flags.md` marks them "derived, not measured". `generic` is the value that loses least
across the three, from the same model. Only the 7100 can be timed here: stage the S8-03 prefetch
M2 pair with each model's values for the lead.
