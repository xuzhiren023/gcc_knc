T2's --short-vector-abi check writes fixed paths `.work/_shared/S5-21/short-vector-O2-{0,1}.mic`. A file created by
one account (the lead or a Claude-backend engineer, both the owner's user) cannot be replaced by the Codex sandbox
account, so T2 failed for engineers four times on 2026-11-14 (S11-12, S12-23, S12-21) and the lead had to rerun it.
Deliver: tools/check.py writes those binaries into a per-run temporary folder under `.work/_state/` (or the
ticket's own folder) and removes it at the end; nothing T2 writes outside that folder. Red first: a host test that
creates an unwritable file at the old path and shows T2 still runs.
