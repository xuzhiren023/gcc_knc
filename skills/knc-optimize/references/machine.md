# Machine inputs for KNC tuning

Snapshot from `knc-machine.yaml` (S13-05), retaining values, units, scope,
applicability and source IDs. V means verified source evidence, R means a
reported measurement, E means an estimate or inference. Verified does not
mean reproduced on the caller's card. Unknown never means zero. Source IDs
resolve in [practices](practices.md#source-editions).

## Card identity

The machine file documents 61 physical cores and 1.238 GHz nominal for 7120P,
60 and 1.05 GHz for its cited 5110P (R15 Table I p.1619; R05 p.5). It leaves
3120 count and clock unknown. Do not fill these from a compiler family preset.
The full/3100/5100 profiles restrict the same production card; they are not
measurements of smaller physical models. See `runner_compute_cores` and
`runner_profile_memory_limit` below.

No isolated ring bandwidth is supplied. Card-wide memory rates include the
whole path. Load latency is not link service time. Physical cache capacity and
translation reach are separate rows. Stencil logical bytes and GEMV weight
bytes are not channel bytes. No smaller-model sustainable rate is established.

IMCI vector width is an interface fact outside the parameter file: 512 bits,
16 fp32 or 8 fp64 elements (R27 section 2.2, pp.28-33; verified early
architectural interface, not a production timing measurement). Timing rows
apply to their named forms, not to every vector operation.

## Using the parameters

For a measured per-thread reciprocal throughput, divide by active siblings
only to derive aggregate cost for that same experiment. Never divide a
dependent chain's latency that way. Never multiply a one-core memory rate by
all cores without modeling shared delivery. Do not sum queue counts from
different sources or request classes. Preserve unknown loaded latency,
scatter completion, production queue capacity and isolated link service rate.

Each row below is one source-file record. Models and profiles are applicability,
not multipliers. An empty list means historical comparison only. Record names
allow a caller to match a later machine-file version. The source file's notes
are retained alongside the numbers.
