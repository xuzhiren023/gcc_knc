# Sources and the claims they support

Ids match `profiles/knc-common.json` `sources` and the gcc_knc reference index
(`docs/research/knc-references.md`). "Supports" lists the model rules or parameters taken from
the source; nothing else is attributed to it.

| Id | Source | Supports |
|---|---|---|
| R01 | Intel, *Xeon Phi Coprocessor System Software Developers Guide*, 328207-001EN, Nov 2012 | four contexts per core; U/V issue; L1 32 KB 8-way; L2 512 KB; 3-clock address setup (p.19); 16-stream, 4 KiB-bounded L2 hardware prefetcher (p.19: `l2.hw_prefetch_streams`, page-bounded streams in the sub-model) with separate enables for data-read and RFO/store prefetches (TUNE_PREFQ: the sub-model trains on stores); ~38 combined outstanding requests (p.19, alternative for the 8-slot limit) |
| R02 | R. Rahman, *Intel Xeon Phi Coprocessor Architecture and Tools*, Apress 2013, ch.3-4 (https://link.springer.com/chapter/10.1007/978-1-4302-5927-5_4) | V-pipe eligible classes (Table 3-1, p.34: mask, vector store, packstore, prefetch, scalar); pairing encoding rules and `cmp/jcc` exception (p.56); imul 10 cycles in the x87 unit (p.56); no back-to-back issue from one context and round-robin picker (ch.4); two-entry prefetch buffer and refill bubble (not modeled); thread-specific pipeline flush on a miss; VPU pipelines and longer paths (pp.32-33, no numbers) |
| R04 | M. Cornea, *Numerical Computation on Intel Xeon Phi Coprocessors*, 2013 | IMCI supports denormals (slow); Intel compilers enable FTZ at -O1+ |
| R06 | Z. | R07 | J. Fang et al., *Test-Driving Intel Xeon Phi*, ICPE 2014 | dependent latency vs aggregate throughput method; 5100-series context for `card-5110p-literature` |

| R27 | Intel, *Xeon Phi Coprocessor Instruction Set Architecture Reference Manual*, 327364-001, Sept 2012 | instruction semantics and operand forms of the subset; merge-only masking; MXCSR FTZ/DAZ bits (§2.4); prefetch hints have no architectural effect (pp.641-656); NGO store semantics (pp.393-398) |
