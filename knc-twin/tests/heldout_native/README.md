# Held-out native validation cases

Kernels predicted first and compared with native measurements that never set a profile
parameter. One harness owns them: `scripts/validate_heldout.py` (the characterization catalog
with `--kernels-s/--kernels-h/--measured`, plus every case directory here with `--cases`).
Results: `characterization-run/validation.md` and `references/validation.md`.

- `measured-characterization.json`, `characterization-run/`: the 119 measured rows of the
  gcc_knc characterization catalog; rows listed in `CALIBRATION_ROWS` set a parameter or exposed
  a rule and are excluded from the held-out statistics.
- One directory per compiled-code or card case: `case.json` (variants, unit, slope rule, rank
  groups, scenario), `measurement.json` (the native log it cites, converted to core cycles;
  `used_to_set_parameters`), `prediction.json` (written by `validate_heldout.py --cases
  tests/heldout_native --record`, deterministic; `tests/regress/test_knc_twin.py` in gcc_knc
  checks it is unchanged for the same engine and profile), and `kernels/` built by the case's
  generator from the binary or objects that ran on the card.

| case | built by | what | unit |
|---|---|---|---|
| s12-31-microbench | `make_s12_31_cases.py` | 68 variants of one x87 row loop from the linked bench binary (`s12-31-bench`): assembler padding 0-15 bytes (`gas_K`), single-byte NOPs (`one_K`), prefix-free NOPs (`pf_K`), loop-top offsets (`mis_K`), loop-body orders; `gas_0`, `adj_0`, `one_15` are calibration rows (x87 and NOP pairing) | core cycles per 27-product row |
| s12-31-hpcg-toy | same | HPCG 3.1 ComputeSPMV_ref and ComputeSYMGS_ref, eight builds each, whole functions from the linked binary, on the 8x8x8 problem the run timed (L2-resident), bench data layout, exact expected results | cycles per timed call |
| s12-31-hpcg-104 | `make_s12_31_hpcg104.py` | the same SpMV builds on a window of interior rows of the 104-cubed problem (memory-bound; `input/` regenerated by the harness, 3 MB, not in git) | cycles per 27 nonzeros |
| s12-30-small | `make_s12_30_cases.py` | the S12-30 gate's four small cases (CSR and HPCG-pointer layout, 13 and 27 nonzeros, 32 rows, random columns into a 32 KiB x) for four builds, timed entry plus kernel from the gate's objects; input from the gate's generator with seed 1 (`input_sensitivity.py` reports the spread over seeds) | cycles per call |
| stream-*-card, gemv-fp32-card | hand-written | card scale (analytical, stand-in core loop) | GB/s; outside the core model, reported apart |

Regenerating (needs the K1OM `objdump`, `KNC_OBJDUMP`, and the shared build directories):

```
python tests/heldout_native/make_s12_31_cases.py --bench .work/_shared/S12-31/build/s12-31-bench --disassembly bench.dis --log .work/_shared/S12-31/native-mb.log --log3 .work/_shared/S12-31/native.log
python tests/heldout_native/make_s12_31_hpcg104.py --bench ... --disassembly bench.dis --log .work/_shared/S12-31/native.log
python tests/heldout_native/make_s12_30_cases.py --objects .work/_shared/S12-30 --log .work/_shared/tmp/claude-s12-window8/s12-30-gate-hpcg.out --batch-out fixtures/batch
```

To add a case: convert the binary that ran (`scripts/from_binary.py`), bind the run's inputs
(file blocks), compute the expected result outside the twin, write `case.json` and
`measurement.json`, run the harness with `--record` before comparing, and never derive a
parameter or overlay from the measurement. A variant whose measurement changed a model rule is
marked `calibrates` in `case.json` and stops counting as held out.
